# What is it?
MDGarden は、Markdown ベースの Wiki / ドキュメントビュアーです。  
公開サーバでは軽量な Markdown ビュアーとして、ローカルサーバではパーソナルな情報管理ツール・ナレッジベースとして運用できます。

## 位置づけ

MDGarden は「情報公開プラットフォーム」よりも、次のような用途を重視した設計です。

- 自分の知識やメモを Markdown で蓄積し、必要なときに読みやすく参照する
- 同じデータを、公開用ビューとローカル運用用ビューで使い分ける
- 最小構成で長く保守できるドキュメント基盤を持つ

## 動作モデル

MDGarden は静的ファイルだけで構成され、ブラウザ上の JavaScript で動作します。

- サーバ側で特別なアプリケーション処理を持たない
- `index.html` と Markdown 群があれば動作できる
- インストール不要で、環境を汚さずに導入できる

## この設計のメリット

- 導入が簡単
- サイズが小さく、持ち運びしやすい
- 実行環境に依存しにくく、ポータビリティが高い
- データと表示を分離しやすく、メンテナンス負荷を抑えやすい

## セキュリティ特性

サーバ側で動くアプリケーション層を持たないため、一般的な Web アプリに比べてアタックサーフィスを非常に小さくできます。  
そのため、構成をシンプルに保ったまま運用しやすいのが強みです。

ただし、ブラウザ上で実行されるスクリプトや外部アセットの扱いには引き続き注意が必要です。詳細は [Security](security.md) を参照してください。

## データ形式としての Markdown

MDGarden は標準的な Markdown をデータとして扱います。

- 可読性が高く、テキストとしてそのまま読める
- 使い慣れたエディタで編集できる
- 特定ツールに閉じないため、データの可搬性が高い

## 連携と移行のしやすさ

Markdown を中核にしているため、他システムとの連携や移行が容易です。

- 生成AIの入出力データとして扱いやすい
- オフィスツールや他のドキュメント基盤へ変換しやすい
- ベンダーロックインを避けながら、最小限の手間で移行できる

## 向いている使い方

- ローカルで育てる個人ナレッジベース
- 小規模公開向けの軽量ドキュメントサイト
- Markdown を長期資産として管理したい運用
