# MDGarden

MDGardenはブラウザ上で完全に動作する、ゼロバックエンドのマークダウンWikiエンジンおよびドキュメントビューアーです。

標準的なMarkdownファイルを、クライアントサイドだけでリッチでインタラクティブなSPA（Single Page Application）に変換。データベースやサーバーサイドの処理は一切不要で、GitHub Pagesなどの静的ファイルホスティングのみで動作します。

ローカル環境（localhost）では、そのままブラウザ上からMarkdownを直接編集・保存できる簡易オーサリングツールとして機能し、ページ一覧やバックリンクを表示するサイトマップファイルの生成、全文検索用のインデックスファイルの生成、オフラインアクセス用のシングルファイルHTMLの生成などの機能を提供します。
